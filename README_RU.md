# Chat Continuity Guard — бесплатное расширение для длинных чатов ChatGPT

**[English README](README.md) · [Главный сайт разработчика: ExpCarry.com](https://expcarry.com/)**

Chat Continuity Guard предупреждает, когда **видимая переписка** становится длинной, и помогает сохранить рабочий контекст для перехода в новый чат.

## Возможности

- Подсчёт сообщений и примерная оценка объёма *отображаемого* текста.
- Настраиваемое предупреждение — изначально 70 сообщений или ~50 000 оценочных токенов.
- Кнопка копирования подробного запроса для создания сводки проекта, пригодной для нового чата.
- Экспорт **видимых сообщений** в локальный Markdown-файл.
- Русский/английский интерфейс по языку браузера (для украинского языка пока используется русский перевод).
- Никаких внешних серверов, аналитики, API-ключей или подписок.

## Как установить в Chrome / Opera

1. На GitHub нажмите **Code → Download ZIP**.
2. Распакуйте репозиторий в постоянную папку.
3. В Chrome откройте `chrome://extensions`, в Opera — `opera://extensions`.
4. Включите **Режим разработчика**.
5. Нажмите **Загрузить распакованное / Load unpacked** и выберите папку с `manifest.json`.
6. Обновите вкладку с ChatGPT и откройте конкретный разговор.
7. Откройте плавающую кнопку справа внизу, чтобы настроить предупреждения и экспорт.

## Важно знать

**Расширение НЕ знает реальный остаток контекстного окна.** ChatGPT не передаёт такие данные через поддерживаемый интерфейс расширения. Это лишь приблизительный ранний индикатор.

Некоторые старые сообщения могут не присутствовать в DOM, включая скрытые результаты инструментов, изображения, файлы и виртуализированные части переписки. Поэтому Markdown-экспорт не является гарантированной полной резервной копией и **не умеет переносить скрытое состояние модели**.

## Приватность

Расширение запрашивает разрешение `storage` (для настроек) и доступ только к `https://chatgpt.com/*`. Оно не передаёт сообщения на сторонние сайты и не перехватывает внутренние запросы ChatGPT. Сохранение переписки происходит только по нажатию кнопки. Подробности — в [PRIVACY.md](PRIVACY.md).
